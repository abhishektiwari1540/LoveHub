## LoveHub — Open-Source Long-Distance Couples App

LoveHub is an open-source relationship platform for long-distance couples to chat, watch together, share moments, and stay emotionally connected. It is designed to make virtual connection simple, fast, and enjoyable for couples who want to stay close from anywhere.

LoveHub is a virtual date platform built for long-distance couples who want to stay connected through chat, shared activities, and memorable experiences. The project focuses on making communication more personal, interactive, and fun with a clean and modern experience.


## Features
-- Real-time chat for couples.
-- Watch together and share entertainment moments.
-- Share photos, memories, and updates.
-- Virtual date-style interaction.
-- Fast and responsive UI.
-- Open-source contribution friendly structure.
-- Built for easy customization and future expansion

## Tech Stack
Frontend: React / TypeScript.
Build tool: Vite.
Backend / Database: Firebase.
Styling: CSS.
Deployment: Ready for modern web hosting.

## Getting Started
Prerequisites
Node.js installed.
npm or yarn installed.
Firebase project configured.
## Installation
bash
git clone https://github.com/your-username/lovehub-long-distance-couples-app.git
cd lovehub-long-distance-couples-app

-- npm install
-- Firebase Setup
## Create a .env file in the root directory and add your Firebase credentials:
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id


## Run Locally
bash
npm run dev
Environment Variables
## Make sure your environment variables match the Firebase project settings. Keep .env private and do not commit it to GitHub.

## Usage
After starting the app locally:
Open the app in your browser.
Sign in or create an account.
Start chatting with your partner.
Explore shared activities and connection features.
Enjoy the virtual date experience.
